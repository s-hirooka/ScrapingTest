# GK-Search 仕様書

## 1. 概要

本アプリケーションは、Google 検索結果画面から関連キーワードを収集し、一覧表示および単語分解を行う Windows デスクトップアプリケーションである。  
製品名は `GK-Search`、アセンブリ説明は「Google関連キーワードリサーチツール」である。

あわせて、Yahoo!知恵袋を対象とした Q&A リサーチ画面の実装も含まれるが、現行メイン画面からは起動ボタンが非表示であり、補助機能または開発途中機能として扱う。

## 2. システム構成

- 開発言語: C#
- アプリ種別: Windows Forms アプリケーション
- 対象フレームワーク: .NET Framework 4.7.2
- 実行形式: `WinExe`
- 主な利用ライブラリ:
  - `Microsoft.Web.WebView2`  
    Google 検索ページの表示と JavaScript 実行に使用
  - `Newtonsoft.Json`  
    WebView2 から取得した JavaScript 実行結果の JSON 解析に使用
  - `AngleSharp`  
    Q&A リサーチ画面での HTML 解析に使用
  - `NMeCab`  
    Q&A リサーチ画面での形態素解析に使用

## 3. 起動仕様

- アプリ起動時、`frmMain` を表示する。
- メイン画面のタイトルにはアセンブリ名とバージョンを表示する。
  - 例: `GK-Search Ver1.0.4.0`
- 起動時に WebView2 を初期化する。
- 起動時にレジストリから製品版パスワード情報を読み取り、トライアル版/製品版を判定する。

## 4. 動作環境・前提条件

- Windows 環境で動作すること。
- WebView2 Runtime が利用可能であること。
- Google 検索へアクセスできるインターネット接続があること。
- Q&A リサーチ機能を利用する場合は、同梱の `dic\ipadic` 辞書および `LibNMeCab.dll` が利用可能であること。

## 5. メイン機能概要

### 5.1 関連キーワード検索

指定したキーワードで Google 検索を実行し、検索結果画面中の関連検索候補を取得する。  
取得したキーワードを次階層の検索語として再検索することで、階層的に関連キーワードを収集する。

### 5.2 単体キーワード抽出

収集済みの関連キーワードを空白区切りで分割し、重複を除外した単語一覧を作成する。

### 5.3 並び替え

収集済みの関連キーワード、および抽出済み単体キーワードを昇順または降順で表示する。

### 5.4 ライセンス制御

トライアル版では、アプリ起動後の検索実行回数を 1 回に制限する。  
製品版パスワードが登録されている場合はこの制限を解除する。

## 6. 画面仕様

## 6.1 メイン画面 `frmMain`

### 入力項目

- キーワード入力欄
  - 検索元となるキーワードを入力する。
- 階層
  - `1` ～ `4` を選択可能。
  - 既定値は `3`。
- 検索結果を消して検索する
  - ON の場合、検索開始前に既存の関連キーワード一覧をクリアする。

### 操作ボタン

- `検索`
  - 関連キーワード検索を開始する。
- `中止`
  - 検索中止フラグを立て、処理途中であれば以後の処理を停止する。
- `昇順`
  - 関連キーワード一覧と単体キーワード一覧を昇順表示する。
- `降順`
  - 関連キーワード一覧と単体キーワード一覧を降順表示する。
- `終了`
  - アプリケーションを終了する。
- `購入はコチラ`
  - 購入案内 URL を既定ブラウザで開く。

### メニュー

- `ヘルプ > 操作マニュアル`
  - 操作マニュアル URL を既定ブラウザで開く。
- `ヘルプ > パスワード`
  - パスワード入力ダイアログを表示する。

### 表示領域

- 関連キーワード一覧
  - 取得した関連キーワードを複数行テキストで表示する。
- 単体キーワード一覧
  - 関連キーワードを空白分割して生成した単語一覧を表示する。
- ステータス表示
  - 検索中の階層表示
  - 完了件数表示
  - 処理時間表示
  - 単体キーワード件数表示
- ブラウザタブ
  - WebView2 を表示するタブを持つ。
  - 検索処理はこの WebView2 を内部的に利用する。

### 非表示要素

- `Q&Aリサーチ` ボタン
  - 実装は存在するが、現状は `Visible = false` で非表示。
- `パスワード取得` ボタン
  - 実装は存在するが、現状は `Visible = false` で非表示。
- `単語を抽出` ボタン
  - 実装は存在するが、現状は `Visible = false` で非表示。
- `重複しているキーワードは表示しない。`
  - チェックボックスは存在するが、現状は `Visible = false`。
  - 現行検索処理では内部的に重複除外を常に行うため、UI 操作対象ではない。

## 6.2 Q&A リサーチ画面 `frmQASerach`

### 目的

Q&A サイトの検索結果から質問タイトル・質問文・URL を取得し、形態素解析で単語候補を抽出する。

### 画面上の要素

- 検索キーワード入力欄
- `検索` ボタン
- Q&A サイト選択チェックボックス
  - Yahoo知恵袋
  - 教えて!goo
  - OKWAVE
  - 発言小町
  - ガールズちゃんねる
- 各サイト用ソート条件コンボボックス
- 抽出単語表示用 `ListView`
- 検索結果表示用 `DataGridView`
  - タイトル
  - Q&Aサイト
  - 質問
  - 開く
- `すべての単語を取得する` ボタン

### 現行実装上の実動作

- 実際に検索処理を行うのは Yahoo知恵袋のみ。
- 他サイト用チェックボックスおよびソート条件は画面上に存在するが、検索ロジックでは未使用。
- 検索階層は固定 `1`。
- `すべての単語を取得する` ボタンは、現状は一覧走査のみで機能未完成。
- URL 列は `DataGridViewButtonColumn` だが、クリック時に URL を開く処理は未実装。

## 7. 関連キーワード検索処理仕様

### 7.1 入力チェック

- キーワード未入力の場合は警告ダイアログを表示し、処理を開始しない。
- トライアル版で 2 回目以降の検索を行おうとした場合は警告ダイアログを表示し、処理を開始しない。

### 7.2 検索処理フロー

1. 必要に応じて既存検索結果をクリアする。
2. 停止フラグを初期化する。
3. 階層数分ループする。
4. その階層で保持している検索語ごとに Google 検索 URL を生成する。
5. WebView2 で Google 検索結果ページを読み込む。
6. JavaScript を実行し、CSS セレクタ `span.dg6jd.JGD2rd` に一致する要素の文字列を取得する。
7. 空文字を除外し、未登録キーワードのみ収集する。
8. 取得キーワードを次階層の検索語配列へ格納する。
9. 全階層終了後、関連キーワード一覧を整列し、単体キーワード一覧を生成する。

### 7.3 検索対象 URL

- Google 検索 URL  
  `https://www.google.com/search?q={URLエンコード済みキーワード}`

### 7.4 重複除外

- 現行実装では `astrData` に既に存在するキーワードを再登録しない。
- そのため、関連キーワード一覧には同一文字列が重複登録されない。

### 7.5 停止処理

- `中止` ボタン押下で停止フラグ `mintStopFlag` を `1` に設定する。
- 検索処理は各待機処理・ページ読込前後・キーワード追加前などで停止フラグを確認し、停止時は即時復帰する。
- ただし `finally` 句は実行されるため、表示上は完了メッセージ形式で件数・処理時間が更新される。

### 7.6 タイムアウト

- ページ読み込み待機は最大 15 秒。
- 15 秒を超えた場合は「ページの読み込みがタイムアウトしました。」として例外扱いにする。

## 8. 単体キーワード抽出仕様

- 分割対象は収集済み関連キーワード全文字列である。
- 区切り文字は半角空白と全角空白。
- 同一単語は 1 件として扱う。
- 表示順は昇順または降順。
- 件数表示は `単体キーワード： n件` 形式とする。

## 9. ライセンス仕様

### 9.1 ライセンス状態

- 初期状態はトライアル版。
- レジストリに正しいパスワードが保存されている場合のみ製品版と判定する。

### 9.2 レジストリ保存先

- キー: `HKEY_CURRENT_USER\SOFTWARE\GKSearch\PassWord`
- 値名: `string`

### 9.3 製品版パスワード

- コード上に固定文字列で保持されている。
- 入力値が一致した場合、レジストリへ保存する。

### 9.4 画面表示

- トライアル版では制限メッセージと購入ボタンを表示する。
- 製品版認証成功後は制限メッセージと購入ボタンを非表示にする。

## 10. エラー処理・例外時挙動

- 想定外例外はメッセージボックスでエラー内容を表示する。
- 主なエラー表示:
  - キーワード未入力
  - パスワード不一致
  - ページ読み込みエラー
  - JavaScript 実行エラー
  - 重大なエラー
- Google 検索結果 HTML 構造変更時は、CSS セレクタが一致せずキーワード取得件数が 0 件になる可能性がある。

## 11. 外部依存・注意事項

- Google 検索結果画面の DOM 構造に依存している。
- 取得対象セレクタは `span.dg6jd.JGD2rd` 固定である。
- サイト側の仕様変更、Bot 対策、地域差分、A/B テストにより取得結果が変動する可能性がある。
- 購入案内 URL、操作マニュアル URL はコード内固定である。

## 12. 既知の実装上の制約

- `InitializeWebView2()` は `async void` であり、呼出し元で初期化完了待機を厳密には行っていない。
- 停止操作時でも最終表示が「検索が完了しました」となる場合がある。
- 関連キーワード件数は累積件数であり、今回検索分だけの件数ではない場合がある。
  - `検索結果を消して検索する` を OFF にした場合、過去の結果を保持するため。
- Q&A リサーチ画面は一部 UI が存在するものの、実装済みなのは Yahoo知恵袋中心で、他サイト処理は未実装。

## 13. 今回の実装読解に基づく補足

- 本仕様書は、ソースコード実装を基準に作成したものである。
- 画面上に存在しても非表示または未接続の機能は、「未使用」「未完成」「現行実装上の実動作」として区別して記載した。
